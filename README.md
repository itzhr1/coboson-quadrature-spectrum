# Discrete quadrature spectrum of composite bosons

Code, data and manuscript sources for

> *Discrete quadrature spectrum of composite bosons: Weyl relation, intensity correlations, and binned homodyne detection* (I. Roditi, CBPF; revised draft v10.12, 4 November 2026).

The paper compares three measurements on an exactly solvable two-fermion composite boson (paired-mode model with a finite Schmidt spectrum): the response to classical drives (Weyl relation of the displacements), periodically binned homodyne quadratures (from which an exact Pauli algebra and a two-party singlet are recovered by a spectral filter and a polar correction), and intensity correlations $g^{(2)}$. Everything numerical in the paper is produced by the scripts in `code/` from the files in `data/`, and every table and figure block in the LaTeX sources is regenerated by `code/make_assets.py`.

## Layout

```
manuscript/   coboson_paper_v10_12.tex      research version (27 pp.)
              undergrad_version_v10_12.tex  annotated advanced-undergraduate version (32 pp.)
              *.pdf                     compiled copies
              figures/figure5_cutoff.tex standalone source of Fig. 5
code/         nonflat.py       binned quadratures on 2^S-dimensional paired-mode spaces (Hadamard transforms),
                               displacement defect, dense and Lanczos filters, diagnostics, smooth POVMs
              flatscan.py      flat spectrum (Dicke ladder): analytic eigenvalue grid, both bin-edge conventions
              bell_raw.py      Bob-optimised CHSH value of the raw sequential state (Appendix A)
              revision_checks.py  regenerates the "fresh" data files
              make_assets.py   regenerates the marked table/figure blocks of both manuscripts from data/
              tests.py         16 assertion-based regression tests
              independent/     cross-checks that share no code with the scripts above (see below)
data/         JSON results; data/README.md documents every file and field
validation/   test log, validation.json, provenance.json (hashes), independent-check outputs,
              history/ (records and review responses of earlier revisions)
```

## Reproducing

Python ≥ 3.11 with NumPy and SciPy (SymPy for two of the independent scripts):

```sh
pip install -r requirements.txt
./reproduce.sh           # unit tests, regeneration of all generated blocks, independent cross-checks
```

Individual steps:

```sh
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s code -p tests.py -v
python code/make_assets.py --manuscript manuscript/coboson_paper_v10_12.tex      # rewrites only the marked blocks
python code/revision_checks.py            # fresh dense examples, flat checks, cutoff curves, smoothing, scale checks
python code/revision_checks.py --extended # adds the 960-step Lanczos run at S = 16 (about 0.5 GiB, slow)
python code/flatscan.py --ranks 8 16 32 64 --output flat_examples.json
python code/nonflat.py --rank 8 --z 0.7 --dense --cutoffs 0.4 0.6 --output dense_example.json
python code/nonflat.py --rank 16 --z 0.8 --steps 240 480 960 --cutoffs 0.4 0.6 --output convergence_example.json
python code/bell_raw.py --ranks 8 16 17 64 --output bell_examples.json
```

Set `OPENBLAS_NUM_THREADS=1` (and `OMP_NUM_THREADS=1`) for repeatable timings. The nonflat Hilbert-space dimension is `2^S`; dense runs are practical to `S ≈ 14`, Lanczos runs to `S = 19`. The archived scans in `data/` (flat ranks to 8000, nonflat Lanczos to 19 modes) took hours and are not rerun by `reproduce.sh`; `validation/provenance.json` records their hashes and origin.

The manuscripts compile with `latexmk -xelatex` (used for the distributed PDFs) or `latexmk -pdf` (packages: `amsmath`, `amssymb`, `amsthm`, `booktabs`, `pgfplots` with `groupplots`, `tikz`, `graphicx`, `lmodern`, `microtype`). All figures are inline PGFPlots; no external image files are needed. A PDF is only properly searchable if the Latin Modern (or `cm-super`) Type 1 fonts are installed; without them pdfTeX silently falls back to bitmap Type 3 fonts with no Unicode mapping. The distributed PDFs were produced with XeLaTeX and the Latin Modern OpenType fonts.

## Independent checks

`code/independent/` contains implementations written separately from the production scripts (direct dense operators, symbolic expansions):

| Script | Checks |
|---|---|
| `verify_rank4_flat.py` | rank-four examples, flat ranks, raw protocol, Bell values |
| `verify_expansions.py` | the dilute expansion of the Weyl defect (SymPy), cutoff and balanced-scale examples |
| `verify_revision_numbers.py` | harmonic-pair defects, large-rank flat rows, geometric-class values against `data/` |
| `verify_cutoff_curves.py` | all 50 stored Fig. 5 points (accepted weights, probabilities, bounds, monotonicity) |
| `independent_review_v5.py` | the reviewer's spot checks of the v5 numbers (rank-four, flat ranks, dense nonflat table, eight-mode identity, Anderson field correlation, oscillator constants); its stored results are in the same directory |

Appendix E of the paper states precisely which quoted numbers these scripts reproduce; the remaining prose statistics of the flat scan (window minima, maxima, medians) are read from the archived JSON files.

## Status of the results

Proved in the paper: the product formula and dilute expansion of the Weyl defect; the bin-margin criterion and the smooth-measurement bounds; the recovery identities, the mixedness criterion and the monotonicity of the success probability in the cutoff; strong convergence of the flat-spectrum construction to the oscillator one with strictly positive vacuum overlap; for infinite spectra with summable Schmidt amplitudes, nonatomicity of the quadrature spectral measures and strong convergence of the binned observables, with convergence of the preparation probability at all but countably many cutoffs. Not established, and stated as open in the paper: a convergence rate for hard binning on the flat spectrum; convergence and positivity of the infinite-mode probabilities at the particular cutoffs 0.4 and 0.6 used in the tables. The numerical tests are regression checks of the finite models, not machine proofs.
